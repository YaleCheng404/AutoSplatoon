# AutoSplatoon 1.0.6

If pairing fails again, click Disconnect and then Connect. The app restarts the ESP32, waits for it to boot, and reconnects over serial. Pair on the Switch again using the installed firmware.

- Each connection attempts to reset the board automatically. Losing controller communication does not restart the board by itself.
- During connection, the app reports progress and temporarily disables port selection, refresh, and flashing. Image processing leaves the connection message visible.
- If the port cannot drive the reset line, the app suggests pressing RST manually and still attempts the normal handshake.

A Windows test build recovered the connection in five of five trials on YD-ESP32 and Switch 2. See [validation](https://github.com/YaleCheng404/AutoSplatoon/blob/master/docs/validation.md) for the test conditions and scope.

The app continues to bundle UARTSwitchCon 1.2 and the same dependencies. Extract the full package when upgrading and recalibrate the console cursor after reconnecting.

Packages are available for Windows x64, macOS 14.4 or later on Apple Silicon, and Linux x64.
