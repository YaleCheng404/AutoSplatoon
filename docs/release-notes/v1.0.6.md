# AutoSplatoon 1.0.6

再次无法配对时，点击“断开连接”再“连接”。软件会重启 ESP32，等待启动后重新连接串口，随后可以在 Switch 上配对，无需重新烧录固件。

- 沿用现有连接按钮、串口选择和手动配对面板。每次连接都会尝试自动复位开发板，通信中断时不会自行重启。
- 连接过程中显示进度，暂时禁用串口选择、刷新和烧录操作。图像处理完成后仍保留连接提示。
- 补充再次配对、手动 RST 和自动复位不可用时的处理方法，整理使用及验证说明。
- 移除文档中未使用的旧预览和生成记录，保留运行资源、示例来源和必要许可证。

Windows 测试构建已在 YD-ESP32（CH340K、ESP32-D0WD-V3 v3.1）和 Switch 2 系统 23.0.1 上验证。首次连接、重刷同一固件后的连接均通过；游戏内使用 Joy-Con 触发断联后，仅通过软件“断开 → 连接”恢复配对和按键响应，五轮成功 5/5。详细范围见 [验证说明](../validation.md)。

内置 UARTSwitchCon 1.2 和依赖版本保持不变，升级软件无需重新烧录。完整解压新发行包后运行，恢复连接后重新校准游戏光标。

提供 Windows x64、macOS 14.4+ Apple Silicon 和 Linux x64 发行包。实机恢复结果限上述 Windows 设备组合；其他板卡及系统仍需各自验证。
