# AutoSplatoon v1.0.4

- 手动控制采用 ClubchatGames 的分区布局：顶部肩键与 L+R 配对、左侧方向键和 L3、右侧 ABXY、底部系统按键；保留全部 18 个鼠标控制按钮。
- 使用现有图标并增加名称提示、按压高亮；小屏与高 DPI 下支持滚动，避免文字和按钮被压缩。
- 松开、切换窗口、关闭弹窗时释放输入；串口断开时关闭弹窗，重新打开不恢复按压。
- 清理未使用的输入编码、遗留图标和播放器统计，保留时序超限保护与现有配对行为。
- 更新手动控制截图、操作文档及参考来源声明。

本地验证：Windows Release 构建、48 项 QtTest、六档 DPI 缩放和 18 个 offscreen GUI 案例通过，图像输出与原基线一致。用户确认检查无问题；本次未提供新增逐项实机测试记录。跨平台发布检查以本标签的 GitHub Actions 为准。

内置 UARTSwitchCon 1.2 固件及依赖版本不变，升级无需重新烧录。完整解压安装包后使用，不单独替换 EXE。
