# AutoSplatoon 1.1.0

The updated workbench brings the canvas, settings, and drawing task into one view. It includes three samples that can be processed offline.

- **Workbench and dialogs.** The canvas sits on the left, with image style and ESP32 settings in the inspector on the right. Progress, estimated time, and pause and stop controls stay at the bottom. Manual Controls, the flashing dialog, and the guide use the same visual style.
- **Three built-in samples.** Open Squid Party, Ink Party, or Controller Lines, adjust the composition, switch among four presets, and export a 320 × 120 PNG. [View the outputs from this release](https://github.com/YaleCheng404/AutoSplatoon/blob/v1.1.0/docs/images/README.md).
- **Source Han Sans and Reduce motion.** The app bundles a Simplified Chinese variable font and offers light, dark, and system themes. Use Reduce motion to disable short transitions in the workbench.

Extract the full package when upgrading. The app continues to use UARTSwitchCon 1.2. See the release assets for Windows x64, Apple Silicon macOS, Linux x64, and the SHA-256 checksum list.
