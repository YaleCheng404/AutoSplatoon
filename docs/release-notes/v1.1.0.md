# AutoSplatoon 1.1.0

新版涂鸦工作台把画布、参数和绘图任务放在同一个视图里，并内置三张可以离线处理的示例。

- **工作台与弹窗更新**。画布在左侧，图像风格和 ESP32 设置集中在右侧检查器。底部固定显示进度、预计用时及暂停和停止按钮。手动控制、烧录和使用指南采用同一套界面样式。
- **三组内置示例**。直接载入「鱿鱼集合」「墨迹派对」或「手柄线稿」，可调整构图、切换四种预设并导出 320×120 PNG。[查看实际处理结果](https://github.com/YaleCheng404/AutoSplatoon/blob/v1.1.0/docs/images/README.md)
- **思源黑体和减少动态效果**。程序内置简体中文可变字体，支持浅色、深色和跟随系统。画布切换和操作反馈支持短过渡，可通过「减少动态效果」停用。

升级时完整解压新发行包后运行。软件继续使用 UARTSwitchCon 1.2。Windows x64、macOS Apple Silicon 和 Linux x64 的下载及 SHA-256 校验清单见发行附件。
