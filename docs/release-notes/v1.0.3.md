# AutoSplatoon v1.0.3

Qt 6 现代界面、多平台自包含安装包、OpenCV 四种图像预设与内置 ESP32 烧录工具。

## 下载

- Windows 10/11 x64：解压 ZIP，运行 AutoSplatoon.exe。
- macOS 14.4+ Apple Silicon：打开 DMG，将 AutoSplatoon.app 拖入“应用程序”。不支持 Intel Mac。
- Linux x64：为 AppImage 添加执行权限后启动；也可解压 tar.gz，运行 AutoSplatoon/AppRun。无 FUSE 时使用 `APPIMAGE_EXTRACT_AND_RUN=1`。

所有平台包含 Qt、OpenCV 所需运行依赖、中文回退字体、esptool 5.4.0 和 UARTSwitchCon 1.2 PRO-UART0.bin。无需 Python 或开发环境；固件地址 0x0，仅支持上游传统 ESP32。SHA256SUMS.txt 提供四个发行包的校验值。源码、依赖锁定文件与许可证随仓库和发行包提供。

## Linux 打包修复

显式部署 offscreen、Wayland 平台及集成插件；部署启动测试移除 SDK 的动态库与插件搜索路径。此前 v1.0.2 的精简容器检查发现插件遗漏，未公开 Release；保留其标签和失败记录。1.0.3 修复发行包部署，不需要重刷固件。

## 主要变化

- 独立 320×120 黑白画布，窗口缩放不改变导出或绘图数据；两个预览页显示蓝色边框与灰色外围，构图时可确认裁切范围。
- 清晰线稿、铅笔素描、纯黑白、经典抖动，支持去噪、细节、线条粗细、阈值、反色与后台处理。
- 串口配对前保留手动控制；正确区分 UART 握手与蓝牙 HID 报告，消除首次配对误超时。连接后在 Switch“更改握法／顺序”中按 L+R 配对，显示手柄通信正常后开始自动绘图。
- 非阻塞蛇形扫描，支持暂停、继续、停止、指定起点和完成保存。
- 烧录内置固件，校验哈希、探测芯片、显示进度，明确处理失败与取消。

## 验证与已知边界

Windows 本地 26 项回归检查通过，1080p/2K/4K × 六档缩放共 18 个 offscreen 案例输出一致；用户已反馈 1.0.2 测试无问题。该反馈未提供板卡型号与逐项测试记录，不能推定全部硬件组合和异常路径已覆盖。

发布任务要求三个平台原生构建、测试和部署检查全部通过，并要求 Linux 在 Ubuntu 24.04、Debian 12 容器启动通过后才统一发布四个产物。模拟高分屏检查不能代替真实跨屏测试。Windows/macOS 尚未正式代码签名或公证；串口驱动和 Linux 设备权限仍需按板卡及系统设置。其他 ESP32 系列和 Switch 2 未验证。

从 1.0.1 升级无需重新烧录固件；从旧版升级应完整解压新软件目录，不要只替换 EXE。
