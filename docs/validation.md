# 验收方法与边界

自动测试与实机验收分开记录；没有开发板/Switch 时不得将硬件步骤标为通过。

CTest 覆盖：蛇形动作回放与准确像素覆盖（单像素、首末列、空行、指定起点、完成保存）；暂停/恢复/停止及重入停止；控制包与 CRC；固件资源哈希；四预设确定性、尺寸和黑白值、透明区域和小图；预览改变大小时合成图不变；连续导入只显示最新结果；模拟 esptool 的成功、芯片探测失败、写入失败及取消（不表示真实烧录通过）。

CI 在 100%、125%、150%、200%、250%、300% 逻辑缩放下执行同一测试。无显示服务器的 offscreen 检查不能替代真实屏幕的视觉验收。正式发布前仍需在 1080p/2K/4K、跨屏移动、X11/Wayland 实际桌面检查主窗口、烧录和手动控制对话框；小窗口参数应可滚动且全部按钮可访问。导出像素应逐像素一致。

发行检查包括：固件 SHA-256、包内 esptool 可执行和版本、脱离 SDK 的启动以及图片处理。`AutoSplatoon --smoke-test` 处理内置测试图后退出；可通过 `AUTOSPLATOON_SMOKE_OUTPUT` 指定已存在的目录保存窗口与 320×120 结果。运行端不需要联网。

图像视觉验收使用同一照片、插画、文字、透明图、小图和纯色图，对照四预设；关注轮廓连续、散点减少、细节辨认。线稿优先连贯轮廓，照片可使用铅笔或经典抖动；效果依赖素材，不保证每张照片都会保留所有细节。

实机待验：传统 ESP32 首次烧录（成功/失败/取消）、Switch 配对、校准、暂停恢复、停止释放按键、USB 断连、响应超时、完整 320×120 绘图及保存。当前支持范围只沿用上游 UARTSwitchCon 的传统 ESP32，不自动扩展到其他 ESP32 系列或 Switch 2。
