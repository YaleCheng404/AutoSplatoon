# 图片展示 AutoSplatoon 的处理效果

`squid-source.png` 为彩色鱿鱼构图，`squid-before-after.png` 展示清晰线稿效果，`squid-presets.png` 展示四种预设。工作台界面见 `squid-workbench.png`。

## 示例采用同一组图像参数

| 参数 | 值 |
| --- | --- |
| 细节 | 50 |
| 去噪 | 1 |
| 线条粗细 | 1 |
| 阈值 | 160 |
| 反色 | 关闭 |

## 素材按各自许可证使用

鱿鱼素材为 [Keebo 的 Splatoon Cursors](https://www.rw-designer.com/cursor-set/splatoon)，发布条款为 Public Domain。原始文件及作者声明位于 `squid-originals/`。Splatoon 角色版权归 Nintendo 所有。

水果图片为 [OpenCV fruits.jpg](https://github.com/opencv/opencv/blob/4.14.0/samples/data/fruits.jpg)，用于照片效果对比。
