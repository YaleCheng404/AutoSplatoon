# 硬件、首次连接与故障排查

## 支持范围

使用带 USB 转串口的传统 ESP32 开发板，例如上游支持的 WROOM/WROVER/PICO。内置 UARTSwitchCon 1.2 使用 Bluetooth Classic、UART0 和 19200 波特率；不支持 ESP32-S2/S3/C3/C6，也未验证 Switch 2。参考 [固件来源与哈希](../firmware/README.md) 和 [上游项目说明](https://github.com/nullstalgia/UARTSwitchCon/tree/1.2)。

通常可直接通过开发板的 USB 转串口连接；自制板或外接串口需按上游及板卡手册确认 UART0、共地和电平，不套用 UART2 固件的接线。USB 线必须支持数据传输。

## 首次使用

1. 连接开发板，刷新串口，选择对应设备。Windows 常见描述为 CH340/CH9102 或 CP210x；不要根据端口编号认定板卡型号。
2. 点击“烧录内置固件”。程序释放串口，使用包内 esptool 探测传统 ESP32，再将已校验的合并固件写入 0x0。日志显示成功后关闭烧录窗口。烧录覆盖开发板原有固件。
3. 点击“连接”，握手成功后进入“手动控制 / 配对”。在 Switch 打开“手柄 → 更改握法 / 顺序”，用软件按 L+R 配对。串口已连接、等待配对的状态下，手动控制仍可使用。
4. 出现“Switch 手柄通信正常 · 可以绘图”后，进入游戏绘图界面并校准光标。起始行列从 0 计数，默认左上角 (0,0)；实际游戏光标必须与软件所选位置一致。先用少量像素测试方向和位置，再绘制完整图片。
5. 导入图片，检查蓝框内的 320×120 结果，选择预设与构图，开始绘图。默认按下和释放各 70 ms；绘制中不要在主机上移动光标或切换页面。

再次使用相同固件无需重刷。升级 1.0.1/1.0.2 软件无需重刷固件；下载后完整解压新软件目录。

## 故障排查

| 现象 | 检查与处理 |
|---|---|
| 没有串口 | 检查数据线、USB 端口和板卡驱动；Windows 设备管理器确认设备，Linux 检查所属组和 dialout 权限，注销后重新登录 |
| 串口无法打开 | 关闭串口监视器、Arduino IDE 或其他占用端口的软件；确认权限和所选端口 |
| 烧录连接失败 | 核对端口与芯片；按住 BOOT 后重试，依据板卡说明使用 RESET；保留日志中的原始错误 |
| 芯片不支持 | 该固件限传统 ESP32；不要绕过芯片检查写入其他系列 |
| 串口已连接，但绘图按钮不可用 | 先完成 Switch 蓝牙配对；只有收到上游 HID 报告才启用自动绘图 |
| 手柄通信中断 | 已有报告停止超过 5 秒时自动停止绘图，串口和手动控制保留；返回配对界面重新连接，重新校准光标后再开始 |
| 绘图位置错位 | 立即停止，核对主机光标与起始行列；系统卡顿可导致时序超限暂停，应先恢复主机和软件状态再继续 |
| 预览灰色区域或图片被裁切 | 灰色为画布外部；仅蓝框内白色画布参与导出和绘图。在“调整构图”页拖动、滚轮缩放或重置 |
| 升级后缺少 DLL | 完整解压发行 ZIP，不单独复制 EXE；包内必须保留 Qt 插件目录、运行库、tools 和其他资源 |

驱动链接和 Linux 权限命令见 [README](../README.md#串口与硬件)。问题反馈请附软件版本、操作系统、板卡型号、USB 转串口型号、Switch 系统/游戏版本、操作步骤及错误日志；不要附访问令牌或其他账号凭证。
